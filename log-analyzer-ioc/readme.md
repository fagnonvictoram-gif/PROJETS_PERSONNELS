Bienvenue sur le mini analyseur de logs creer par l'etudiant FAGNON VICTOR Abdoul Malik . Concretement il s'agit d'un simple programme qui permet d'identifier ou plus precisement de rechecher des mots cles situes dans le fichier blacklist.txt ( vous pouvez modifier a souhait la liste ) dans un long fichier logs.txt ( le nom doit etre maintenue pour le bon fonctionnement du programme ) . Si vous souhaiter l'utiliser voici comment proceder : 
1-) Apres avoir obtenu le dossier deplacer le logs a analyser dans le repertoire ..\log-analyzer-ioc ( vous aurez un chemin d'acces du type \log-analyzer-ioc\logs.txt)

2-) Une fois le fichier logs.txt present lancer le mode gestion_DE_la_blacklist pour ajouter des mots ou celui rechercher.py pour rechercher directement des mots au sein de la blacklist

3-) enfin suivez les differentes etapes pour pouvoir profiter au maximum de l'efficacite du projet
